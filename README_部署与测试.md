# 简记 V1.1.0：Android PWA 版

基于 V1.0.6.1，完整保留其记账逻辑、数据结构（V5）、页面布局及主要功能。新增 PWA 安装、离线缓存、手动确认更新与应用状态说明。

## 上传步骤（腾讯云 CloudBase 静态网站托管）

1. 解压 ZIP，得到 `jianji-pwa-v1.1.0` 文件夹。
2. 登录腾讯云 CloudBase 控制台，进入「静态网站托管」；使用其提供的 HTTPS 测试域名。
3. 上传 `jianji-pwa-v1.1.0` 文件夹**内部的全部文件和 icons 子目录**，让根目录直接包含 `index.html`、`sw.js`、`pwa.js`、`manifest.webmanifest`、`version.json`、`icons/`。不要把整个 ZIP 当成网页文件上传。
4. 手机在 Chrome / Edge 打开分配的 HTTPS 地址。进入「备份与设置 → 手机安装与离线使用」核对离线状态。
5. 通过浏览器菜单「添加到主屏幕」或应用内的「添加到手机桌面」（当浏览器支持安装提示时）。国内部分 Android 仅提供快捷方式，仍可一键打开。
6. 完全在线加载一次，等待“离线文件已准备好”，然后打开飞行模式，关闭再从桌面打开并新增测试账目。重新启动后检查数据，导出 JSON 备份。

## 重要说明

- 只能用 HTTPS（或开发用 localhost）启用 Service Worker。双击 HTML (`file://`) 无法安装完整 PWA。
- 此版本无需云数据库：**账目存储在同一个网站来源的手机浏览器存储中**。静态托管不会自动收到你的账目；我们没有第三方追踪脚本或上传账目代码。
- 当前核心账目存储仍优先使用 localStorage，受限时回退 IndexedDB 或临时备份模式；**尚未进行完整 IndexedDB 重构**。请保留独立 JSON 备份。
- 从旧版 `file://` 打开方式切换为 HTTPS 地址，本地数据不会自动迁移；可用同 V5 格式 JSON 在新网址通过「覆盖恢复」导入。
- 换浏览器、换域名、清除网站数据、卸载 PWA 或手机重置都可能丢失本地账目。PWA 不会自动把账目同步到其他设备。
- 请长期保持相同 HTTPS 域名及路径，以免数据隔离。云平台免费测试域名可能有限流或提示页；若影响安装或经常改变，需选更稳定的域名。
- 有更新时页面顶部显示更新提示，不会自动刷新输入中的表单。手动确认更新后会刷新；请先保存操作。程序缓存与账本数据分离。
- 更新时应将 `sw.js` 中 `CACHE_NAME` 的版本名和其他资源同步更新，并重新上传全部文件。避免单独覆盖 index.html 造成缓存与页面不同步。
- CloudBase 静态托管最好将 `sw.js` / `index.html` / `version.json` 设置为较短缓存时间，以免发布后长时间无法检测新版。

## 文件用途

- `index.html`：保留原记账页面和 V5 账本逻辑（核心 JS 与 V1.0.6.1 相同）
- `pwa.js`：安装提示、检查更新、离线状态，不读写账本数据
- `sw.js`：完整应用外壳缓存、手动确认更新，不缓存账目/备份
- `manifest.webmanifest`：名称、图标、桌面运行配置
- `icons/`：桌面图标和适配自适应图标
- `version.json`：发布版本标记（不存储个人账目）
