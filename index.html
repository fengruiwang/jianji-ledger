选择分类

分类记录买了什么；渠道记录在哪里买或付给谁。默认“其他日常消费”，也可以选择京东、盒马或自定义商家。

拆分明细

订单总金额由各明细金额自动汇总，不需要选择额外的总分类。每项可以填写用途备注；退款可精确关联明细。

关联原消费

退款会冲减选中的商品类别。

¥

退款不算收入；从原消费的支出、分类和消费平台统计中扣除。跨月退款也归属原消费月份，实际到账日期仍会保留。

备份与设置

导出我的数据

JSON 保存本版工具的完整数据，可用于备份恢复；CSV 可用 Excel 打开；退款单独列为负金额，并保留实际退款日期及原消费归属日期。

导入已有备份

合并：保留当前记录，按记录 ID 跳过重复；覆盖恢复：用备份内容完全替换当前记录。支持当前 V5 格式（含 V1.0.6.1）的 JSON 备份；退款信息包含在备份中。

清空本机账本及设置

会清空本机的账目、预算、快捷模板、周期规则以及自定义分类。建议先导出完整 JSON 备份，删除后无法撤销。

快捷记账模板管理

在「记一笔」时勾选“保存为快捷模板”即可新增；在这里可删除不再使用的模板。

自定义收支分类

默认分类可隐藏；自定义分类可以修改、删除。已使用的分类不能删除，但可隐藏，历史记录仍会统计。

分类预算
